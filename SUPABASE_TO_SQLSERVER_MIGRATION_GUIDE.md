## 1. 项目现状分析

### 1.1 技术栈
- **前端**: React + TypeScript + Vite + TailwindCSS
- **当前后端**: Supabase (PostgreSQL + Auth + Storage)

## 2. Supabase 表结构梳理

### 2.1 核心业务表

#### 2.1.1 `departments` - 部门表
```sql
-- PostgreSQL (Supabase)
CREATE TABLE departments (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  code TEXT UNIQUE,
  description TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

**字段说明**:
- `id`: 自增主键
- `name`: 部门名称（唯一）
- `code`: 部门编码
- `description`: 部门描述
- `created_at/updated_at`: 时间戳

---

#### 2.1.2 `employees` - 员工表
```sql
-- PostgreSQL (Supabase)
CREATE TABLE employees (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  employee_id TEXT NOT NULL UNIQUE,
  name TEXT NOT NULL,
  department_id BIGINT REFERENCES departments(id) ON DELETE SET NULL,
  email TEXT,
  position TEXT,
  auth_user_id TEXT,  -- 关联 Supabase Auth 用户ID
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_employees_department ON employees(department_id);
CREATE INDEX idx_employees_employee_id ON employees(employee_id);
CREATE INDEX idx_employees_name ON employees(name);
CREATE INDEX idx_employees_auth_user ON employees(auth_user_id);
```

**字段说明**:
- `id`: UUID 主键
- `employee_id`: 员工工号（唯一）
- `name`: 员工姓名
- `department_id`: 关联部门
- `email`: 邮箱（用于登录）
- `auth_user_id`: 关联认证系统用户ID（**迁移时需替换为自建认证表**）
- `is_active`: 是否在职

---

#### 2.1.3 `skills` - 技能表
```sql
-- PostgreSQL (Supabase)
CREATE TABLE skills (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  module_id INT NOT NULL,
  module_name TEXT NOT NULL,
  skill_name TEXT NOT NULL,
  skill_code TEXT UNIQUE,
  description TEXT,
  display_order INT DEFAULT 0,
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(module_id, skill_name)
);

CREATE INDEX idx_skills_module ON skills(module_id);
CREATE INDEX idx_skills_active ON skills(is_active);
CREATE INDEX idx_skills_order ON skills(display_order);
```

**字段说明**:
- `id`: 自增主键
- `module_id`: 模块ID（1-TPM基础, 2-精益流程, 3-问题解决等）
- `module_name`: 模块名称
- `skill_name`: 技能名称
- `display_order`: 显示顺序

---

#### 2.1.4 `competency_assessments` - 能力评估表
```sql
-- PostgreSQL (Supabase)
CREATE TABLE competency_assessments (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  employee_id UUID REFERENCES employees(id) ON DELETE CASCADE NOT NULL,
  skill_id BIGINT REFERENCES skills(id) ON DELETE CASCADE NOT NULL,
  current_level INT NOT NULL CHECK (current_level BETWEEN 1 AND 5),
  target_level INT NOT NULL CHECK (target_level BETWEEN 1 AND 5),
  gap INT GENERATED ALWAYS AS (target_level - current_level) STORED,
  assessment_year INT DEFAULT EXTRACT(YEAR FROM NOW()),
  assessment_date DATE DEFAULT CURRENT_DATE,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(employee_id, skill_id, assessment_year),
  CHECK (target_level >= current_level)
);

CREATE INDEX idx_assessments_employee ON competency_assessments(employee_id);
CREATE INDEX idx_assessments_skill ON competency_assessments(skill_id);
CREATE INDEX idx_assessments_year ON competency_assessments(assessment_year);
CREATE INDEX idx_assessments_gap ON competency_assessments(gap);
```

**字段说明**:
- `id`: UUID 主键
- `employee_id`: 关联员工
- `skill_id`: 关联技能
- `current_level`: 当前等级 (1-5)
- `target_level`: 目标等级 (1-5)
- `gap`: 差距（自动计算）
- `assessment_year`: 评估年份

### 2.2 Supabase Auth 用户表（系统表）

Supabase 内置的认证系统使用 `auth.users` 表，包含：
- `id`: UUID 主键
- `email`: 邮箱
- `encrypted_password`: 加密密码（OTP 模式下为空）
- `email_confirmed_at`: 邮箱确认时间
- `created_at/updated_at`: 时间戳

**迁移策略**：需自建认证表和 JWT Token 管理。

## 3. Supabase API 接口梳理

### 3.1 认证接口（authService.ts）

#### 3.1.1 发送注册验证码
```typescript
// Supabase
await supabase.auth.signInWithOtp({
  email: data.email,
  options: {
    shouldCreateUser: true,
    data: { name: data.name }
  }
});
```

**对应 API**: `POST /api/auth/signup/send-otp`
- 输入: `{ email, name }`
- 输出: `{ success: true, message: "验证码已发送" }`
- 业务逻辑: 生成6位OTP，发送邮件，存入临时表（5分钟过期）

---

#### 3.1.2 验证 OTP 并完成注册
```typescript
// Supabase
await supabase.auth.verifyOtp({
  email: data.email,
  token: data.token,
  type: 'email'
});
```

**对应 API**: `POST /api/auth/signup/verify-otp`
- 输入: `{ email, token, name }`
- 输出: `{ access_token, refresh_token, user: {...} }`
- 业务逻辑: 验证OTP，创建用户记录（users + employees），生成JWT

---

#### 3.1.3 发送登录验证码
```typescript
// Supabase
await supabase.auth.signInWithOtp({
  email: data.email,
  options: { shouldCreateUser: false }
});
```

**对应 API**: `POST /api/auth/login/send-otp`
- 输入: `{ email }`
- 输出: `{ success: true, message: "验证码已发送" }`
- 业务逻辑: 检查用户是否存在，生成OTP并发送

---

#### 3.1.4 验证 OTP 并登录
```typescript
// Supabase
await supabase.auth.verifyOtp({
  email: data.email,
  token: data.token,
  type: 'magiclink'
});
```

**对应 API**: `POST /api/auth/login/verify-otp`
- 输入: `{ email, token, rememberMe }`
- 输出: `{ access_token, refresh_token, user: {...} }`
- 业务逻辑: 验证OTP，生成JWT（根据 rememberMe 设置过期时间）

---

#### 3.1.5 获取当前会话
```typescript
// Supabase
await supabase.auth.getSession();
```

**对应 API**: `GET /api/auth/session`
- 输入: Header `Authorization: Bearer <token>`
- 输出: `{ user: {...}, session: {...} }`
- 业务逻辑: 验证JWT，返回用户信息

---

#### 3.1.6 登出
```typescript
// Supabase
await supabase.auth.signOut();
```

**对应 API**: `POST /api/auth/logout`
- 输入: Header `Authorization: Bearer <token>`
- 输出: `{ success: true }`
- 业务逻辑: 撤销/删除 refresh_token

## 4. SQL Server 表结构转换

### 4.1 数据类型映射

| PostgreSQL (Supabase) | SQL Server |
|----------------------|------------|
| `BIGINT GENERATED BY DEFAULT AS IDENTITY` | `BIGINT IDENTITY(1,1)` |
| `UUID DEFAULT gen_random_uuid()` | `UNIQUEIDENTIFIER DEFAULT NEWID()` |
| `TEXT` | `NVARCHAR(MAX)` 或 `NVARCHAR(500)` |
| `TIMESTAMPTZ` | `DATETIMEZONE` 或 `DATETIME2` |
| `BOOLEAN` | `BIT` |
| `SERIAL` | `INT IDENTITY(1,1)` |
| `TEXT[]` (数组) | `NVARCHAR(MAX)` (存JSON) 或额外关联表 |
| `CHECK (status IN (...))` | `CHECK (status IN (...))` 或 `CONSTRAINT` |
| `GENERATED ALWAYS AS (...)` | `AS (...)` (计算列) |

---

### 5.5 JWT 工具（utils/jwt.py）

```python
# app/utils/jwt.py
from datetime import datetime, timedelta
from jose import JWTError, jwt
from ..config import settings

def create_access_token(data: dict, expires_delta: timedelta = None):
    """生成访问令牌"""
    to_encode = data.copy()
    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(minutes=settings.JWT_ACCESS_TOKEN_EXPIRE_MINUTES)
    
    to_encode.update({"exp": expire, "type": "access"})
    encoded_jwt = jwt.encode(to_encode, settings.JWT_SECRET_KEY, algorithm=settings.JWT_ALGORITHM)
    return encoded_jwt

def create_refresh_token(data: dict):
    """生成刷新令牌"""
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(days=settings.JWT_REFRESH_TOKEN_EXPIRE_DAYS)
    to_encode.update({"exp": expire, "type": "refresh"})
    encoded_jwt = jwt.encode(to_encode, settings.JWT_SECRET_KEY, algorithm=settings.JWT_ALGORITHM)
    return encoded_jwt

def decode_token(token: str) -> dict:
    """解码并验证令牌"""
    try:
        payload = jwt.decode(token, settings.JWT_SECRET_KEY, algorithms=[settings.JWT_ALGORITHM])
        return payload
    except JWTError:
        return None
```

### 5.6 认证服务（services/auth_service.py）

```python
# app/services/auth_service.py
import random
import string
from datetime import datetime, timedelta
from typing import Optional
import pyodbc
from ..config import settings
from ..utils.jwt import create_access_token, create_refresh_token

def generate_otp(length: int = 6) -> str:
    """生成数字验证码"""
    return ''.join(random.choices(string.digits, k=length))

def validate_email_domain(email: str) -> bool:
    """验证邮箱域名"""
    domain = email.split('@')[-1].lower()
    return domain in settings.ALLOWED_EMAIL_DOMAINS

def save_otp(conn: pyodbc.Connection, email: str, token: str, otp_type: str):
    """保存 OTP 到数据库"""
    cursor = conn.cursor()
    expires_at = datetime.utcnow() + timedelta(minutes=settings.OTP_EXPIRE_MINUTES)
    
    cursor.execute("""
        INSERT INTO otp_tokens (email, token, type, expires_at, created_at)
        VALUES (?, ?, ?, ?, GETDATE())
    """, (email, token, otp_type, expires_at))
    conn.commit()

def verify_otp(conn: pyodbc.Connection, email: str, token: str, otp_type: str) -> bool:
    """验证 OTP"""
    cursor = conn.cursor()
    cursor.execute("""
        SELECT id FROM otp_tokens
        WHERE email = ? AND token = ? AND type = ? 
          AND expires_at > GETDATE() AND used = 0
    """, (email, token, otp_type))
    
    row = cursor.fetchone()
    if row:
        # 标记为已使用
        cursor.execute("UPDATE otp_tokens SET used = 1, used_at = GETDATE() WHERE id = ?", (row.id,))
        conn.commit()
        return True
    return False

def create_user(conn: pyodbc.Connection, email: str, name: str) -> str:
    """创建用户并返回 user_id"""
    cursor = conn.cursor()
    cursor.execute("""
        INSERT INTO users (email, name, email_confirmed, email_confirmed_at, created_at, updated_at)
        OUTPUT INSERTED.id
        VALUES (?, ?, 1, GETDATE(), GETDATE(), GETDATE())
    """, (email, name))
    
    user_id = cursor.fetchone()[0]
    conn.commit()
    return str(user_id)

def get_user_by_email(conn: pyodbc.Connection, email: str) -> Optional[dict]:
    """根据邮箱获取用户"""
    cursor = conn.cursor()
    cursor.execute("SELECT id, email, name, is_active FROM users WHERE email = ?", (email,))
    row = cursor.fetchone()
    if row:
        return {"id": str(row.id), "email": row.email, "name": row.name, "is_active": bool(row.is_active)}
    return None

def generate_tokens(user_id: str, email: str) -> dict:
    """生成访问令牌和刷新令牌"""
    access_token = create_access_token(data={"sub": user_id, "email": email})
    refresh_token = create_refresh_token(data={"sub": user_id})
    return {"access_token": access_token, "refresh_token": refresh_token, "token_type": "bearer"}
```

```python
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
from ..config import settings

def send_otp_email(to_email: str, otp: str, purpose: str = "登录"):
    """发送 OTP 验证码邮件"""
    subject = f"BPS 系统 - {purpose}验证码"
    body = f"""
    <html>
      <body>
        <h2>您的验证码是：<strong>{otp}</strong></h2>
        <p>验证码有效期为 {settings.OTP_EXPIRE_MINUTES} 分钟。</p>
        <p>如果这不是您本人的操作，请忽略此邮件。</p>
      </body>
    </html>
    """
    
    msg = MIMEMultipart("alternative")
    msg["Subject"] = subject
    msg["From"] = settings.SMTP_FROM_EMAIL
    msg["To"] = to_email
    
    html_part = MIMEText(body, "html")
    msg.attach(html_part)
    
    try:
        with smtplib.SMTP(settings.SMTP_HOST, settings.SMTP_PORT) as server:
            server.starttls()
            server.login(settings.SMTP_USER, settings.SMTP_PASSWORD)
            server.sendmail(settings.SMTP_FROM_EMAIL, to_email, msg.as_string())
        return True
    except Exception as e:
        print(f"邮件发送失败: {e}")
        return False
```

```python
# app/routers/auth.py
from fastapi import APIRouter, Depends, HTTPException, status
from pydantic import BaseModel, EmailStr
from ..database import get_db
from ..services.auth_service import (
    validate_email_domain, generate_otp, save_otp, verify_otp,
    create_user, get_user_by_email, generate_tokens
)
from ..services.email_service import send_otp_email

router = APIRouter(prefix="/api/auth", tags=["Authentication"])

# ==================== 数据模型 ====================
class SignupSendOTPRequest(BaseModel):
    email: EmailStr
    name: str

class VerifyOTPRequest(BaseModel):
    email: EmailStr
    token: str

class LoginSendOTPRequest(BaseModel):
    email: EmailStr

# ==================== 注册流程 ====================
@router.post("/signup/send-otp")
async def signup_send_otp(req: SignupSendOTPRequest, conn = Depends(get_db)):
    """发送注册验证码"""
    # 1. 验证邮箱域名
    if not validate_email_domain(req.email):
        raise HTTPException(status_code=400, detail="只允许使用 @bosch.com 或 @bshg.com 邮箱")
    
    # 2. 检查邮箱是否已注册
    user = get_user_by_email(conn, req.email)
    if user:
        raise HTTPException(status_code=400, detail="该邮箱已注册，请直接登录")
    
    # 3. 生成 OTP
    otp = generate_otp()
    save_otp(conn, req.email, otp, "signup")
    
    # 4. 发送邮件
    if not send_otp_email(req.email, otp, "注册"):
        raise HTTPException(status_code=500, detail="验证码发送失败，请稍后重试")
    
    return {"success": True, "message": f"验证码已发送到 {req.email}"}

@router.post("/signup/verify-otp")
async def signup_verify_otp(req: VerifyOTPRequest, conn = Depends(get_db)):
    """验证 OTP 并完成注册"""
    # 1. 验证 OTP
    if not verify_otp(conn, req.email, req.token, "signup"):
        raise HTTPException(status_code=400, detail="验证码无效或已过期")
    
    # 2. 创建用户
    user_id = create_user(conn, req.email, req.name)
    
    # 3. 生成令牌
    tokens = generate_tokens(user_id, req.email)
    
    return {
        **tokens,
        "user": {"id": user_id, "email": req.email, "name": req.name}
    }

# ==================== 登录流程 ====================
@router.post("/login/send-otp")
async def login_send_otp(req: LoginSendOTPRequest, conn = Depends(get_db)):
    """发送登录验证码"""
    # 1. 检查用户是否存在
    user = get_user_by_email(conn, req.email)
    if not user:
        raise HTTPException(status_code=404, detail="用户不存在，请先注册")
    
    if not user["is_active"]:
        raise HTTPException(status_code=403, detail="账户已被禁用")
    
    # 2. 生成 OTP
    otp = generate_otp()
    save_otp(conn, req.email, otp, "login")
    
    # 3. 发送邮件
    if not send_otp_email(req.email, otp, "登录"):
        raise HTTPException(status_code=500, detail="验证码发送失败")
    
    return {"success": True, "message": f"验证码已发送到 {req.email}"}

@router.post("/login/verify-otp")
async def login_verify_otp(req: VerifyOTPRequest, conn = Depends(get_db)):
    """验证 OTP 并登录"""
    # 1. 验证 OTP
    if not verify_otp(conn, req.email, req.token, "login"):
        raise HTTPException(status_code=400, detail="验证码无效或已过期")
    
    # 2. 获取用户信息
    user = get_user_by_email(conn, req.email)
    if not user or not user["is_active"]:
        raise HTTPException(status_code=403, detail="账户不可用")
    
    # 3. 生成令牌
    tokens = generate_tokens(user["id"], user["email"])
    
    return {
        **tokens,
        "user": user
    }

# ==================== 会话管理 ====================
@router.get("/session")
async def get_session(token: str = Depends(oauth2_scheme), conn = Depends(get_db)):
    """获取当前会话"""
    from ..utils.jwt import decode_token

    if not payload:
        raise HTTPException(status_code=401, detail="Invalid token")
    
    user_id = payload.get("sub")
    user = get_user_by_id(conn, user_id)  # 需实现此函数
    
    if not user:
        raise HTTPException(status_code=404, detail="User not found")
    
    return {"user": user, "session": {"access_token": token}}

@router.post("/logout")
async def logout():
    """登出（客户端删除 token）"""
    return {"success": True, "message": "已登出"}
```

## 9. 风险与应对

### 9.1 技术风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| SQL Server 性能不足 | 查询慢 | 优化索引、使用视图缓存、增加服务器资源 |
| FastAPI 并发瓶颈 | 响应慢 | 使用多进程部署（Gunicorn workers） |
| 邮件发送失败 | 无法登录 | 配置备用 SMTP、添加重试机制 |
| JWT Token 泄露 | 安全风险 | HTTPS + 短过期时间 + Refresh Token |

---

### 9.2 数据风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 数据迁移丢失 | 数据不完整 | 迁移前全量备份、逐表验证行数 |
| 外键约束冲突 | 导入失败 | 先导入父表（departments, skills）再导入子表 |
| 时区问题 | 时间错误 | 统一使用 UTC 或服务器本地时区 |

---

### 9.3 业务风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 用户无法登录 | 业务中断 | 提供管理员后台手动绑定邮箱 |
| 导入数据格式不兼容 | 导入失败 | 提供详细错误提示、支持多种格式 |
