# BPS Compass 品牌文案更新设计

## 目标

将所有面向用户的平台旧名称统一为 `BPS Compass`，并在适合展示品牌副标题的位置使用固定 Slogan：

`Guide the Right people to the Right projects.`

## 修改范围

- 登录后侧边栏的平台名称和副标题；
- 登录、注册、OTP 登录、邮箱绑定和个人资料设置页面中的平台名称；
- 上述认证页面的品牌副标题和页脚；
- 浏览器标签页标题；
- 其他用户可见且明确指代平台的“BPS 能力与排程平台”“BPS 能力管理系统”“BPS 管理系统”等旧名称。

## 实现方式

- 新增前端品牌常量，集中保存平台名称、Slogan 和页脚文本；
- React 页面和组件统一引用品牌常量，避免文案重复及后续不一致；
- `index.html` 的静态页面标题直接设置为 `BPS Compass`；
- 页面空间允许时显示完整 Slogan，不截断或改写用户确认的大小写与标点。

## 保留内容

以下内容属于业务名称或角色名称，不作为平台品牌替换：

- `BPS elements` 等能力模块和技能数据；
- `BPS Engineer` / `BPS_ENGINEER` 等业务角色及代码枚举；
- `BPS工程师日程管理`、`BPS 能力与任务全景驾驶舱`等功能页面标题；
- 数据导入示例、历史记录和诊断报告中的业务数据。

## 验收标准

- 用户正常操作可到达的界面不再显示平台旧名称；
- 主要品牌区域显示 `BPS Compass` 和完整 Slogan；
- 页脚显示 `© 2026 Bosch BPS Compass`；
- 浏览器标签页显示 `BPS Compass`；
- 业务术语、能力数据、角色权限和接口行为不受影响；
- 前端单元测试、类型检查和生产构建通过。

## 非目标

- 不修改数据库、后端 API 或历史数据；
- 不重新设计 Logo、颜色、字体或页面布局；
- 不修改仅供开发使用的旧文档和历史截图。
