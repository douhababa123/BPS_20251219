## Context

趋势接口已有年度基线、筛选和逐月历史回放。明细必须和柱高使用同一计算过程。

## Decisions

- 在现有进度接口增加可选 `include_details=true`，仅抽屉请求时返回逐技能数据；普通趋势响应不增加大体积明细。
- 逐技能明细从 `build_competency_progress` 选中月份回放后的 `values` 产生，不另写一套 GAP 算法。名称由原基线技能、员工关联查询提供。
- 前端分别请求被点击月份，核对年度、月份、模块、人员、基线 ID 和明细 GAP 合计与原柱值；不一致时提示刷新，不展示错误明细。
- 当前月沿用接口返回的上海时间截止点，历史月沿用月末截止点。

## Risks / Trade-offs

- 历史数据或年度基线可能在用户打开抽屉前被修改。前端进行一致性校验，避免把新版本误呈现为旧柱子的构成。
- 团队范围可能有较多技能单元。抽屉内滚动，不改变整页布局。
