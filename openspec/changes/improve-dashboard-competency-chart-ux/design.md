## Context

本次审计覆盖侧边栏可进入的“总览”和“能力画像”正式页面，共 8 个图表实例：

- 总览：1 个 GAP 总分/关闭率组合趋势图。
- 能力画像团队差距分析：模块/技能 GAP 分布、人员 GAP 分配、季度 GAP 趋势，共 3 个。
- 能力画像总分视图：九模块平均分雷达图、模块平均分对比图，共 2 个。
- 能力画像个人视图：能力雷达图、GAP 分布图，共 2 个。

日程管理中的 4 个图表和隐藏入口“旧日历”中的 3 个图表按用户要求保持原样，不属于此次变更。

## Audit Findings

### 跨页面一致性

- 同一语义在不同图表中使用不同颜色：GAP 分别使用蓝、青、紫、红，用户需要重复理解。
- 卡片标题、中英文字段、图例位置、坐标字体、网格线和 Tooltip 风格不统一。
- 多数图表只有鼠标悬停值，没有足够的可访问文字摘要；部分图表没有空数据状态。

### 总览

- 双 Y 轴缺少明确的轴标题，必须结合图例推断左轴为 GAP、右轴为百分比。
- 图例顺序与主要阅读顺序不完全一致，折线点较小，当前选中月份没有足够的视觉强调。
- 当前 Tooltip 数据准确，应保留其精确值和 `年初 GAP 为 0` 的业务提示。

### 能力画像／团队差距分析

- 九模块名称较长，竖向柱图必须旋转标签，仍出现拥挤和阅读距离过长。
- 人员 GAP 图同时展示 19 人，姓名倾斜且密集；切换到技能时最多 38 个类别，竖向柱图不可读。
- 季度趋势的缺失季度已经正确保留为空，但缺失状态和有效折线之间的视觉说明较弱。

### 能力画像／总分视图

- 九轴雷达图超过常规推荐的 5–8 轴，但它是已确认的业务视图，因此保留并优化，而不是删除。
- 模块平均分柱图使用倾斜长标签；改为水平分组柱图后可完整显示名称并更容易比较 0–4 的差异。
- 当前/目标已有数据标签和 0–4 上限，应保持。

### 能力画像／个人视图

- 九模块雷达图可作为整体轮廓保留，但标签在较窄卡片中会被裁切。
- 技能模式可能包含 38 个轴，存在精确比较和长名称阅读限制；用户已明确要求该技能雷达图保持现状，因此本次记录问题但不修改。
- GAP 柱图同样使用倾斜长标签；水平排序能更直接显示优先提升项。

## Goals / Non-Goals

- Goals: 提高数据可读性、跨页面一致性、精确比较能力、响应式表现和基础无障碍质量。
- Non-goals: 不改业务数据、计算公式、数据排序口径、权限、筛选器含义、日程管理、旧日历或应用外壳导航。

## Decisions

### 1. 建立固定的图表语义色

- 现状 Current：Bosch 蓝 `#2563EB`。
- 目标 Target：橙色 `#EA580C`。
- GAP：红色 `#DC2626`；在仅展示 GAP 的单系列团队汇总中允许使用深蓝主色，但同一图内不混用语义。
- 关闭率 Close rate：青绿色 `#0F766E`，避免与目标橙色混淆。
- 无数据/辅助信息：Slate 灰色系。

颜色之外继续使用系列名称、点形、数值标签或线型表达含义，不让颜色成为唯一信号。所有文字和数据标记以浅色背景下的可读对比度为准。

### 2. 图表类型服从数据结构

- 时间趋势继续使用折线图或柱线组合图。
- 九模块整体轮廓继续使用雷达图。
- 模块、人员和技能的数值比较统一优先使用水平条形图，名称固定在左侧，不旋转。
- 个人视图的技能雷达图作为明确例外保持现状，不改图表类型、布局或交互。

模块/人员/技能分布继续沿用现有业务排序。类别过多时使用固定可视高度加内部纵向滚动，每一项保留足够行高，而不是压缩到同一屏或截断名称。

### 3. 统一卡片与信息层级

每个图表卡片使用一致结构：中文主标题、轻量英文副标题或业务说明、右侧筛选器/切换器、图例、绘图区、必要的数据质量说明。标题不再把中英文无间隔拼接为一个视觉块。

卡片边框、圆角和阴影沿用现有 BPS Compass 样式，不引入渐变背景、重阴影或装饰动画。图表网格只保留帮助读数的主方向网格，并降低对比度。

### 4. 精确值与状态

- 已有业务要求的数据标签继续保留；密集图表只在有值的条形或关键点上显示，避免大量 `0` 标签形成噪声。
- Tooltip 统一展示完整名称、指标名称、格式化值和单位。
- 无数据时显示明确空状态，不渲染空坐标框。
- 加载和失败状态沿用页面现有请求状态，不把旧数据伪装为新筛选结果。
- 季度趋势中的无历史数据继续保持 `null`，不得显示为 0。

### 5. 总览组合图

保留“GAP 总分柱 + GAP 关闭率折线”的业务结构。左轴标明 `GAP 总分`，右轴标明 `%`；图例按 GAP、关闭率顺序排列。突出所选 YTD 月份的柱/点，并保证该月 Tooltip 与顶部 KPI 使用相同格式化函数和数值。

### 6. 雷达图约束

总分视图和个人模块视图保留九模块雷达图。通过增加图表内边距、对长模块名做受控换行、将图例放在稳定位置、增加 Tooltip 和区别明显的描边/填充来改善可读性。坐标范围固定为 0–4，不做视觉裁剪或数据钳制。个人技能雷达图不套用这些改动，保持当前展示。

### 7. 响应式与无障碍

- 宽屏保持当前双栏布局；较窄内容区自动变为单栏。
- 水平条形图保留完整名称；必要时内部滚动，不产生页面级横向滚动。
- 为每个图表容器提供描述其主题、范围和主要系列的 `aria-label`/文字摘要。
- 图表动画尊重 `prefers-reduced-motion`；数据在动画结束前也必须可读取。
- 应用外壳在 390px 下仅剩约 134px 主内容宽度属于全局导航响应式问题，本次不扩大范围修改；图表组件仍保证在其可用容器内不额外制造页面级横向溢出。

## Risks / Trade-offs

- 水平条形图会增加部分页面纵向长度。通过限定可视高度与内部滚动控制页面长度，同时保留全部数据。
- 雷达图九轴仍不是精确比较的最佳形式。保留它是为了满足既有业务确认，并同时提供更精确的模块平均分水平条形图。
- 共享展示常量可能造成过度抽象。只提取确实在多处重复的颜色、Tooltip 和空状态，不建立新的图表框架。

## Verification

1. 业务回归：相同输入下所有图表数值、筛选结果和数据顺序不变。
2. 视觉回归：在 1440×1000、1024×768 和窄内容区检查标签不被裁切、图例不重叠、无页面级横向滚动。
3. 交互回归：模块/技能切换、人员选择、季度筛选和 Tooltip 正常。
4. 无障碍回归：图表具有可识别名称，颜色不是唯一表达，减少动态效果设置生效。
5. 范围回归：`Schedule.tsx` 与 `Calendar.tsx` 无任何差异。

## Confirmed Constraints

- 用户已确认：个人视图“技能”雷达图保持现状，不替换为水平分组条形图。
- 用户已确认：日程管理和旧日历页面保持现状。
